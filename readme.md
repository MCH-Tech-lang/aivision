 # MCH Vision 2.0 - Модуль сбора датасета

Модульная система компьютерного зрения на базе Python и OpenCV. Программа предназначена для захвата видеопотока, отслеживания движения, детекции лиц под разными углами и сбора датасета для последующего обучения распознающих нейросетей.

## Архитектура проекта
Код спроектирован в соответствии с принципами объектно-ориентированного программирования (ООП) и разделения обязанностей (Single Responsibility Principle). Это позволяет легко масштабировать систему в будущем (например, увеличивать количество камер до 6 или переходить на инференс моделей YOLO).

- Video_source: класс для абстракции от аппаратной части. Отвечает только за подключение к камере, чтение сырых кадров и освобождение ресурсов.
- securityanalyzer: аналитический движок системы. Занимается матричными преобразованиями, вычислением разности пикселей и логикой детекции.
- Visionapp: главный управляющий класс (диспетчер приложения). Координирует передачу кадров между источником и анализатором, а также управляет выводом окон на экран.

## Оптимизация производительности
Логика оптимизирована для работы на вычислительных устройствах с ограниченными ресурсами (процессоры Intel Celeron, микрокомпьютеры Orange Pi):
- Каскадное переключение: для минимизации нагрузки по умолчанию работает каскад haarcascade_frontalface_default. Если лицо в анфас не найдено, система мгновенно переключается на haarcascade_profileface, что позволяет не терять объект при повороте головы.
- Попиксельная разность: вычисление разности матриц (cv2.absdiff) используется для фиксации факта движения перед запуском ресурсоемких функций.

## Запуск приложения
1. Разместить файлы каскадов Хаара в локальной папке проекта.
2. Указать корректные абсолютные пути к .xml файлам в конструкторе класса securityanalyzer.
3. Запустить скрипт через терминал:
python vision2.0.py

Для корректного завершения программы и освобождения памяти нажмите клавишу "q" в активном окне видеопотока.
