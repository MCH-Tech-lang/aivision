Home AI Security Complex - Vision 1.0Программа для мониторинга периметра, автоматического обнаружения лиц и сбора эталонных биометрических датасетов на базе OpenCV.Ключевые особенности архитектурыОптимизированный двухступенчатый конвейер ИИ: Динамическое переключение между фронтальным каскадом (haarcascade_frontalface_default.xml) и профильным сканером (haarcascade_profileface.xml). Если лицо не обнаружено в анфас, система подключает боковой сканер, снижая постоянную нагрузку на процессор.Динамическая ракурсная память: Автоматическая независимая нумерация файлов для каждого человека через f-строки и инкремент счётчиков объекта. Система позволяет формировать базу данных без риска перезаписи старых кадров.Двойной поток вывода: Одновременный вывод цветного BGR-потока и бинарной матрицы (градации серого) для отладки работы классификатора в реальном времени.Установка и запускУстановите необходимую зависимость:bashpip install opencv-python
Используйте код с осторожностью.Скачайте официальные каскады Хаара из репозитория OpenCV и положите их в корневую папку проекта рядом со скриптом:haarcascade_frontalface_default.xmlhaarcascade_profileface.xmlЗапустите главный модуль:bashpython vision_camera.py
